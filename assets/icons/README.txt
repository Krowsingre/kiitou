Kiitou theme icon pack

Seven theme-matched ICO files: teal, purple, gold, blue, green, red, silver.

Each .ico contains 16, 24, 32, 48, 64, 128, and 256 pixel images.
The icon design is sourced from the approved Kiitou routed-K icon.
The region outside the rounded-square boundary is transparent; the interior remains opaque.
The matching PNG masters are included for implementation convenience.

For theme switching, update your app window and notification-area icon using the matching ICO resource. Windows may continue to use the executable default for its shell shortcut and file icon.
